# NAVPLAY – Interaktives Navigationslabor

Ein kostenlos hostbares Schulprojekt zu Navigationsarten, Interaktionen, Responsive Navigation und Accessibility.

## Lokal öffnen
`index.html` im Browser öffnen. Keine Installation und keine externen Bibliotheken erforderlich.

## Online veröffentlichen (GitHub Pages)
1. Kostenloses GitHub-Konto anlegen oder anmelden.
2. Neues **öffentliches** Repository namens `navplay` erstellen.
3. Die Dateien `index.html`, `style.css`, `script.js` in das Hauptverzeichnis hochladen (nicht nur die ZIP-Datei).
4. Unter **Settings → Pages → Build and deployment** als Quelle **Deploy from a branch** wählen.
5. Branch `main`, Ordner `/(root)` auswählen und speichern.
6. Nach der Veröffentlichung unter `https://BENUTZERNAME.github.io/navplay/` öffnen. Das kann einige Minuten dauern.

## Hinweise
- Alle Inhalte sind fiktive Demonstrationsinhalte.
- Die Seite benötigt keine Datenbank und erhebt selbst keine Nutzerdaten.
- Die Responsive-Vorschau verwendet drei Beispielbreiten. Sie ersetzt keine vollständige Prüfung auf echten Geräten.
